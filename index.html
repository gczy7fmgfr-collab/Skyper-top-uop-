# Skyper — ដាក់ឱ្យដំណើរការ (Deploy) នៅលើ Vercel + Neon (ឥតគិតថ្លៃ, ប្រហែល ១០ នាទី) ## ជំហានទី ១ — បង្កើតមូលដ្ឋានទិន្នន័យ Neon (២ នាទី) 1. ចូលទៅកាន់ https://neon.tech → **Sign up** (ការចូលប្រើគណនី GitHub គឺលឿនបំផុត) 2. បង្កើត Project → ដាក់ឈ្មោះថា `rithtopup` → ជ្រើសរើសតំបន់ (region) ជា **Singapore** (ជិតកម្ពុជាបំផុត) 3. ចម្លង (Copy) **connection string** — ដែលមានទម្រង់ដូចនេះ៖ ``` postgresql://neondb_owner:xxxxx@ep-xxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require ``` **រក្សាទុកវា** — អ្នកនឹងត្រូវការវាចំនួន ២ ដង។ ## ជំហានទី ២ — ដាក់កូដ (Push code) ទៅកាន់ GitHub (៣ នាទី) នៅក្នុងថត (folder) នៃ project របស់អ្នក៖ ```powershell git init git add . git commit -m "Initial commit" ``` បន្ទាប់មក នៅលើ https://github.com/new សូមបង្កើត repository ថ្មីមួយប្រភេទ **private** ដែលមានឈ្មោះថា `rithtopup` → ចម្លងពាក្យបញ្ជា (commands) ដែល GitHub បង្ហាញ → បិទភ្ជាប់ (paste) ចូលទៅក្នុង terminal។ ជាធម្មតាគឺ៖ ```powershell git remote add origin https://github.com/YOUR_USERNAME/rithtopup.git git branch -M main git push -u origin main ``` ## ជំហានទី ៣ — បញ្ចូលទិន្នន័យដំបូង (Seed) ទៅក្នុង Neon DB នៅលើម៉ាស៊ីនរបស់អ្នក (១ នាទី) បង្កើតឯកសារ `.env` បណ្ដោះអាសន្នមួយនៅក្នុង project៖ ``` DATABASE_URL="" JWT_SECRET="any-long-random-string-min-32-chars-hereeeeee" ADMIN_EMAIL="admin@skyper.example" ADMIN_PASSWORD="YOUR_STRONG_ADMIN_PASSWORD" PAYMENT_SIMULATION_MODE="true" NEXT_PUBLIC_BASE_URL="http://localhost:3000" ``` បន្ទាប់មកដំណើរការពាក្យបញ្ជា៖ ```powershell npx prisma db push npm run db:seed ``` ជំហាននេះនឹងបង្កើតតារាង (tables) ទាំងអស់នៅក្នុង Neon និងបញ្ចូលទិន្នន័យហ្គេម រួមទាំងគណនី admin របស់អ្នក។ ## ជំហានទី ៤ — ដាក់ឱ្យដំណើរការលើ Vercel (៣ នាទី) 1. ចូលទៅកាន់ https://vercel.com → **Sign up with GitHub** 2. ចុច **Add New… → Project** → Import យក repository ឈ្មោះ `rithtopup` របស់អ្នក 3. **Framework Preset**: Next.js (ប្រព័ន្ធនឹងរកឃើញដោយស្វ័យប្រវត្តិ) 4. ពង្រីកផ្នែក **Environment Variables** → បន្ថែមទាំងអស់នេះ៖ | Name | Value | |---|---| | `DATABASE_URL` | string សម្រាប់តភ្ជាប់ Neon របស់អ្នក | | `JWT_SECRET` | string ចៃដន្យដែលមានតួអក្សរ ៣២ ដូចគ្នានឹងជំហានទី ៣ | | `ADMIN_EMAIL` | `admin@skyper.example` | | `ADMIN_PASSWORD` | ពាក្យសម្ងាត់ admin របស់អ្នក | | `PAYMENT_SIMULATION_MODE` | `true` | | `NEXT_PUBLIC_BASE_URL` | **ទុកទំនេរសម្រាប់ពេលនេះ** (នឹងត្រូវកែសម្រួលក្រោយពេល deploy) | | `KHPAY_BASE_URL` | `https://khpay.site/api/v1` | | `KHPAY_API_KEY` | (ទុកទំនេរ — ដោយសារបើក sim mode) | | `KHPAY_WEBHOOK_SECRET` | (ទុកទំនេរ) | 5. ចុច **Deploy** → រង់ចាំប្រហែល ២ នាទី ## ជំហានទី ៥ — ការកំណត់ក្រោយពេល Deploy (៣០ វិនាទី) 1. បន្ទាប់ពី deploy ជោគជ័យ សូមចម្លង URL នៃគេហទំព័ររបស់អ្នក (ឧទាហរណ៍៖ `https://skyper.vercel.app`) 2. ចូលទៅកាន់ **Project Settings → Environment Variables** → កំណត់តម្លៃ `NEXT_PUBLIC_BASE_URL` ទៅជា URL នោះ 3. **Deployments → Redeploy** → រួចរាល់ ## ✅ គេហទំព័រដំណើរការហើយ - គេហទំព័រសម្រាប់សាធារណៈ៖ `https://skyper.vercel.app` - ផ្នែក Admin៖ `https://skyper.vercel.app/admin/login` ## ប្រើប្រាស់ Domain ផ្ទាល់ខ្លួន (ជាជម្រើស អាចធ្វើពេលក្រោយ) Project Settings → **Domains** → បន្ថែម domain របស់អ្នក → Vercel នឹងផ្តល់ឱ្យអ្នកនូវ DNS records ដើម្បីយកទៅដាក់ក្នុងប្រព័ន្ធរបស់អ្នកចុះបញ្ជី domain (registrar)។ ត្រូវការពេល ៥-៣០ នាទីដើម្បីឱ្យការកំណត់នេះមានប្រសិទ្ធភាពពេញលេញ។ ## នៅពេលអ្នករួចរាល់សម្រាប់ការទូទាត់ពិតប្រាកដ កំណត់ `PAYMENT_SIMULATION_MODE=false` ហើយបំពេញ `KHPAY_API_KEY` និង `KHPAY_WEBHOOK_SECRET` ដែលទទួលបានពីផ្ទាំងគ្រប់គ្រងអ្នកលក់ (merchant dashboard) របស់ KHPay របស់អ្នក រួចធ្វើការដាក់ឱ្យដំណើរការឡើងវិញ (redeploy)។
